# Frontend Projects

A collection of frontend projects created during my software development
journey, exploring different technologies, frameworks, and tools.

## Projects

| Project | Description | Technologies |
|---|---|---|
| [Modern CV](./modern-cv/) | A responsive personal CV website. | HTML, CSS |
| [NordicBrew](./nordic-brew/) | A responsive coffee shop website with interactive menu filters. | HTML, CSS, JavaScript |
| [Personal Portfolio](./personal-portfolio/) | A personal portfolio presenting my background, skills, and projects. | React, Vite |
| [Sjöbo Books](./sjobo-books/) | A bookshop demo with book search, pagination, and a persistent shopping cart. | React, Vite, Bootstrap, React Router |
